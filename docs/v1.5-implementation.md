# V1.5 实现与验收记录

本页记录当前 V1.5 在 AppKit 工程中的实现边界与可验证证据。`FR-13 最近访问` 已按产品决策移出范围，应用不再采集或保存访问记录。

## FR-12 收藏

- 文件和文件夹均可从文件列表右键菜单收藏；未收藏时菜单显示“添加到收藏”，已收藏时显示“从收藏移除”。
- 收藏保存在当前 macOS 用户的 Application Support SQLite 数据库中，不同步到 SVN 或远端服务。
- 应用内执行 SVN move 后，会同步更新收藏目标及文件夹下后代目标的 URL。
- 打开收藏前使用实时 `svn info --xml` 校验；目标不存在时标记“已失效”，仍允许从侧边栏移除。
- 移除服务器时同时删除该服务器的收藏、目录缓存和搜索索引。

## 目录缓存与侧边栏状态

- 首次进入目录时执行 `svn list --xml` 并将结构化条目和缓存时间写入 GRDB。
- 再次进入已缓存目录时直接显示本地结果，不重复等待 SVN；工具栏“刷新”强制读取服务端并覆盖当前目录缓存。
- 写操作成功后清除该服务器的目录缓存，重新加载当前目录，并只刷新侧边栏中对应的目录分支。
- 右侧文件区使用 `NSOutlineView`；展开节点按 URL 读取同一套目录缓存，刷新时保留展开集合，缓存代次变化后按需重新加载已展开分支。
- 侧边栏展开、收起和当前选中项使用稳定状态键写入 UserDefaults，重启或数据分支刷新后恢复。
- 收藏变化只增量刷新“我的收藏”节点，不重建服务器目录树。

## FR-14 文件名搜索

- 搜索范围支持“当前目录”和服务器配置的默认起始路径。
- 首次搜索时按需执行 `svn list --xml --recursive` 建立本地索引，不阻塞应用启动。
- 后续输入只查询本地 SQLite 索引；支持大小写不敏感的文件/文件夹名称包含匹配。
- 工具栏可手动更新索引，状态栏显示索引时间、结果数量和更新状态；索引任务可以取消。
- 搜索索引只保存文件名与 SVN 列表元数据，不读取或保存 Word、PDF 等文件正文。
- 打开文件结果前通过实时 `svn info` 校验存在性和当前 revision；目录结果通过实时列表读取校验。

## 自动化验证

- 元数据迁移可与已有服务器配置迁移共用应用数据库。
- 收藏失效、目录重命名后代路径同步、目录缓存替换与清理均有数据库测试。
- 目录往返不重复请求、手动刷新强制请求，以及侧边栏状态跨实例恢复均有自动化测试。
- 当前目录/配置范围、本地索引复用、大小写不敏感匹配、索引时间和实时 revision 校验均有 ViewModel 测试。
- 真实临时 SVN 仓库集成测试覆盖递归 XML 列表以及原有 V1 读写操作。
