# V1.5 实现与验收记录

本页记录 `FR-12`～`FR-14` 在当前 AppKit 工程中的实现边界与可验证证据。

## FR-12 收藏

- 文件和文件夹均可从文件列表右键菜单添加或移除收藏。
- 收藏保存在当前 macOS 用户的 Application Support SQLite 数据库中，不同步到 SVN 或远端服务。
- 应用内执行 SVN move 后，会同步更新收藏目标及文件夹下后代目标的 URL。
- 打开收藏前使用实时 `svn info --xml` 校验；目标不存在时标记“已失效”，仍允许从侧边栏移除。
- 移除服务器时同时删除该服务器的收藏、最近访问和搜索索引。

## FR-13 最近访问

- 成功进入目录和成功打开文件后记录访问；同一 URL 再次访问会更新时间而非新增重复记录。
- 全局最多保留最新 50 条。
- 记录只包含服务器配置 ID、仓库 URL、名称、类型、最后已知 revision 和访问时间。
- 连接页面拒绝在 URL 中嵌入用户名或密码；密码继续只保存在 Keychain。
- 可在应用菜单“设置…”中查看数量并清空，也可从侧边栏“最近访问”菜单清空。

## FR-14 文件名搜索

- 搜索范围支持“当前目录”和服务器配置的默认起始路径。
- 首次搜索时按需执行 `svn list --xml --recursive` 建立本地索引，不阻塞应用启动。
- 后续输入只查询本地 SQLite 索引；支持大小写不敏感的文件/文件夹名称包含匹配。
- 工具栏可手动更新索引，状态栏显示索引时间、结果数量和更新状态；索引任务可以取消。
- 搜索索引只保存文件名与 SVN 列表元数据，不读取或保存 Word、PDF 等文件正文。
- 打开文件结果前通过实时 `svn info` 校验存在性和当前 revision；目录结果通过实时列表读取校验。

## 自动化验证

- 元数据迁移可与已有服务器配置迁移共用应用数据库。
- 收藏失效、目录重命名后代路径同步、最近访问去重和 50 条上限均有数据库测试。
- 当前目录/配置范围、本地索引复用、大小写不敏感匹配、索引时间和实时 revision 校验均有 ViewModel 测试。
- 真实临时 SVN 仓库集成测试覆盖递归 XML 列表以及原有 V1 读写操作。
