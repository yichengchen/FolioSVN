# 交互与界面设计

## 1. 体验目标

客户端应让用户感觉自己在使用企业网盘，而不是开发工具。主要对象是“文件”和“文件夹”，主要动作是“打开、下载、上传、替换、重命名和删除”。SVN revision 作为版本信息保留，但不占据首要视觉层级。

## 3. 页面布局

### 3.1 顶部工具栏

- 仓库名称/切换入口。
- 后退、前进与刷新。
- 搜索框。
- “上传”主按钮。
- “新建文件夹”和更多操作。

### 3.2 左侧边栏

- 我的收藏。
- 仓库目录树。
- 目录节点按需展开，加载时在节点旁显示轻量进度。

### 3.3 内容区

- 顶部面包屑展示当前位置。
- 默认使用列表视图，目录排在文件前。
- 用户可调整列宽，排序状态按仓库保存。
- 单击选中，双击目录进入，双击文件执行“下载并打开”。

### 3.4 底部状态区

- 连接状态和最后刷新时间。
- 后台传输数量与入口。
- 错误时提供简短状态，详细信息进入任务面板查看。

## 5. 核心交互流程

### 5.1 上传新文件

```text
点击上传/拖入文件
        ↓
校验名称与当前目录
        ↓
名称不存在 ────────────── 名称已存在
        ↓                         ↓
填写/确认提交说明          转入替换确认页
        ↓
上传并提交
        ↓
刷新列表并提示新版本号
```

- 支持将 Finder 文件拖入当前目录。
- 多文件上传前展示文件清单和总大小。
- 用户关闭窗口不应取消后台任务。

### 5.2 替换文件

确认页必须回答“用什么替换什么”：

```text
替换“接口说明.pdf”？

仓库当前版本   r12580 · 2.5 MB · 今天 09:30
本地文件       2.7 MB · 今天 11:42

提交说明  [更新：接口说明.pdf                  ]

                         [取消] [替换文件]
```

如果确认后远端发生变化：

```text
文件已经被其他人更新

仓库中的“接口说明.pdf”在你开始操作后产生了新版本。
为避免覆盖他人的修改，请刷新后重新确认。

                              [保留本地文件] [刷新]
```

### 5.3 重命名

- 在列表中进入行内编辑，或由右键菜单打开小型弹窗。
- 默认全选名称、不选中文件扩展名。
- 提交说明可在展开区域中修改。
- 成功后短暂提示“已重命名，历史版本已保留”。

### 5.4 删除

文件确认：

```text
删除“旧版报价.xlsx”？

此操作会提交到仓库。文件仍可通过历史版本找回，
但当前目录中将不再显示。

                              [取消] [删除]
```

目录确认还需显示：

```text
该文件夹及其中的全部内容都会从当前版本删除。
```

产品不使用“移到废纸篓”文案，因为没有独立回收站。

### 5.5 下载并打开

```text
双击文件
   ↓
检查本地缓存是否匹配 revision
   ↓
命中缓存 ── 是 ──→ 默认应用打开
   │
   否
   ↓
后台下载 → 完整性检查 → 默认应用打开
```

如果文件较大，显示可取消的下载进度；任务完成前不启动默认应用。

### 5.6 查看历史与恢复

历史使用右侧检查器或独立窗口：

```text
接口说明.pdf · 历史版本

● r12580  张三  今天 09:30
  更新接口认证章节
  [下载此版本]

● r12520  李四  8月10日
  上传接口说明
  [下载此版本] [恢复此版本]
```

恢复时明确说明：系统会以历史内容创建一个新版本，不会删除选中版本之后的历史。

## 6. 搜索体验

- 输入后展示文件名匹配结果，并标出匹配片段。
- 每条结果显示名称、所在路径、类型、修改时间和修改人。
- 结果页顶部显示搜索范围与索引时间。
- 点击文件夹进入对应位置；双击文件下载并打开。
- 没有结果时建议检查关键词或刷新索引，不承诺内容全文检索。

## 7. 状态设计

### 7.1 目录状态

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 骨架行或进度指示，不显示假数据 |
| 空目录 | “这个文件夹是空的”，并提供上传/新建入口 |
| 无权限 | 锁图标与“没有查看此文件夹的权限” |
| 网络失败 | 保留可用缓存，顶部显示离线和重试按钮 |
| 缓存数据 | 明确显示最后更新时间 |

### 7.2 任务状态

任务面板中的每项包含：操作类型、对象、进度、开始时间和状态。支持取消进行中的网络/导出任务，失败项提供重试和查看原因。

### 7.3 通知策略

- 成功：使用短暂、非阻塞提示；重要操作包含新 revision。
- 可恢复失败：提供重试。
- 需要决策：使用模态确认。
- 原始 SVN 错误仅放在“技术详情”折叠区，默认展示用户语言。

## 8. 常用错误文案

| 场景 | 主文案 | 建议操作 |
| --- | --- | --- |
| 认证失败 | 无法登录仓库，请检查用户名或凭据 | 重新输入 |
| 权限不足 | 你没有修改这个位置的权限 | 联系管理员 |
| 网络中断 | 连接已中断，尚未提交任何更改 | 重试 |
| 远端已更新 | 文件已被其他人更新，未执行替换 | 刷新后重试 |
| 名称冲突 | 当前文件夹已存在同名项目 | 修改名称或替换 |
| 证书异常 | 无法验证服务器身份 | 查看证书详情/取消 |
| 本地磁盘不足 | 可用空间不足，下载未完成 | 更换位置 |

## 10. 无障碍与本地化

- 所有图标提供文本标签和 VoiceOver 描述。
- 表格支持完整键盘导航和排序状态朗读。
- 颜色不是状态的唯一载体。
- 时间、数字和文件大小按系统区域格式显示。
- 中文为首发语言时，代码层仍使用可本地化字符串资源，避免硬编码。
