# SVN 企业文档客户端文档

本目录描述一款面向企业内部文档管理场景的 macOS SVN 客户端。产品在底层复用 SVN 的版本控制能力，在界面与操作层提供接近网盘和 Finder 的体验。

## 产品定位

> 面向企业内部的 SVN 文档管理客户端：弱化 SVN 概念，强化网盘体验。

主要服务于已经使用 SVN 长期存储合同、制度、项目资料、技术文档等文件，但不希望普通员工接触 Working Copy、Branch、Merge、Conflict 等开发术语的组织。

## 版本路线

| 阶段 | 目标 | 核心内容 |
| --- | --- | --- |
| V1 | 核心可用 | 仓库浏览、下载/打开、上传、替换、删除、重命名、新建文件夹、查看信息、复制位置 |
| V1.5 | 提升大仓库体验 | 收藏、最近访问、文件名搜索 |
| V2 | 发挥 SVN 价值 | 文件历史、下载历史版本、恢复历史版本；文本差异可选 |
| V3 | 企业增强 | 权限提示、操作记录与审计体验 |

## 明确不做

- 回收站：SVN 历史已可追溯删除和恢复，首期不增加独立回收站模型。
- 分支、标签和合并：不符合普通文档用户的心智模型。
- Working Copy 状态展示：不向用户暴露 modified、conflicted 等开发术语。
- 首期全文检索：Word、PDF 等格式解析与全仓扫描成本较高，先提供文件名搜索。
